# PushStream Public Frontend V2 — Visual Tokens

The V2 tokens are defined in `app/globals.css` with the `--ps-*` prefix so the redesign can coexist with the existing public theme while pages migrate incrementally.

## Core colors

- `--ps-navy: #071b4a`
- `--ps-navy-2: #0d285e`
- `--ps-blue: #0877ff`
- `--ps-blue-hover: #0068e6`
- `--ps-blue-soft: #eaf4ff`
- `--ps-surface-soft: #f5faff`
- `--ps-border: #dce9f7`
- `--ps-text: #142447`
- `--ps-muted: #66789b`
- semantic green/violet/orange/red/yellow tokens

## Geometry

- content: `1280px`
- wide content: `1380px`
- article: `840px`
- radii: `8 / 12 / 16 / 22px`
- section spacing: fluid `54–88px`

## Reference characteristics encoded

- deep navy heavy headings
- electric-blue CTAs
- white cards with pale blue-gray borders
- low-elevation shadows
- large split heroes with soft blue gradients
- floating white hero chips
- compact uppercase blue labels
- blue newsletter band
- responsive card and hero behavior
